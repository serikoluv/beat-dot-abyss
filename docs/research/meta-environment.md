# ドットアビス 環境メタ・評価情報

最終更新: 2026-08-18。主ソースは醜女氏note（6/12, 7/2, 7/21, 8/2）と wikiru。
**評価は日付付きの生モノ**として扱う（バランス調整・新装備で変わる）。

## 1. 環境の構造（2026-08 時点）

- **「バックFC（情熱の【崩壊】）連打」が環境の主軸**。フロントFCはほぼ撃たない。
  崩壊2連打で敵防御を実質0にでき、厄災のアサルトゲージ削りもこれで行う。
- **フォレストマント**（FC発動毎に攻撃+50%累積）により**バック配置というだけで強い**。
  フロント版が存在しないためフロントは構造的に不遇。フロントは回避型単機（ヒュメナ等）
  ＋バック6のような編成も一般的。
- **情熱 vs 衝撃**: 情熱=装備・育成なしで完成する安定型（初心者向け）。
  衝撃=ユニーク装備（漆黒のドレス/弓/ナックル等の紋章供給）と育成が揃うと質で上回る大器晩成。
- 大剣はユニーク装備が全滅レベルで不遇。「大剣の時点でそのキャラは不遇」（醜女氏）。
- 状態異常はこちらが使う分には弱い（ボスに通らない）。凍結・状態異常ビルドは現状評価低。

## 3. キャラ評価の要点（醜女氏、育成後評価 7/21・8/2 反映）

### 最重要キャラ
- **ミルティーユ**（バック/情熱/土/魔導書・ルクスノヴァ）: 圧倒的最強。全体回復＋状態異常解除
  ＋FCでバックに情熱ばら撒き。リセマラ最優先。
- **メリッサ**（アシスト/情熱/土・交換所限定）: 15秒毎マナチャージ（アビ10で2）＋ドロップ増加。
  「システムに組み込んでよいレベル」。最優先確保・最優先アビ育成。
- **シャノン**（R/バック/情熱/銃）: 自前防御デバフで崩壊軸の核。R最強格（耐久は絆HPで補強）。
- **ヒナギ**（バック/情熱/水/魔導書）: バック・ヒーラー・情熱で全部噛み合う。恒常SSRの当たり。

### 役割別の注目
- タンク: ウェンディ（割合自己回復＋被回復で衝撃、無育成で機能）、シルヴィア（デバフタンク、
  FCトークンはフロントFC環境が来れば）
- 衝撃アタッカー: エレクトラ（雑魚一掃・TA最強）、エティア（育成後バーサーカー化）、
  クリスティ（味方スキル発動で自身チャージ＝超回転、星詠み杖と）
- デバッファー: フレデリカ（貴重な攻撃デバフ＋回復。VH7以降・高難度で評価急騰）、
  ハツネ（喪失＋衝撃消費2で漆黒アーマー起動役）
- アシスト: エミリー（開幕マナ＋耐性）、ピコ（衝撃供給の要。衝撃環境の到来で評価急騰）、
  ジェンマ（FCでマナ2還元→アシストFC実質1コスト）、マリナ（情熱ばら撒き）
- 回避型: ヒュメナ（1凸＋漆黒ナックルで一軍。フロント単機運用）、ニナ恒常（拳の衝撃という
  一点で龍牙ナックル起動役=衝撃パの潤滑油）
- 逆風: ラヴェリア・ラモーナ・マニョリア（無凸性能が低い/紋章供給不全。マニョリアは完凸級で大化け）

### SR/R の実用枠
マーガレット（CT25全体回復）、ヒマリ（高耐久バック全体攻撃）、ノエミ（R情熱ヒーラー）、
アヤメ（SR・衝撃供給が揃うと防御デバフ45%級）

## 4. 検証済みの罠・バグ知見（データ化時の注意）

- 効果テキストと実挙動の乖離が多発。修正は「実挙動（有利な方）に合わせて上方修正」される
  傾向（マーガレットCT60→25正式化、ミルティーユ魔導書50%→10%だが旧仕様は不発だったので実質強化）。
- ナーフ実績: フォレストマント（累積可→不可）、深蝕のライフル（付与時50%→消費時30%）。
  強すぎる組み合わせ（エレクトラ＋ピコ＋漆黒供給ループ）が発端。
- 開幕紋章付与系の装備・アビスコードは紋章違い事故の地雷（§game-spec 3）。
- リザルトの調査ポイント表示バグ（表示のみ、実計算は正しい）。

## 5. 編成テンプレの現在解

1. **情熱崩壊軸（入門〜汎用）**: フロント=タンク1〜2 / バック=情熱染め＋SSRヒーラー1
   （ミルティーユ/ヒナギ）＋シャノン / アシスト=メリッサ＋自由。バックのクリスタルは【崩壊】、
   フロント枠クリスタルは外す（オート干渉回避）。バック全員フォレストマント。
- 2. **衝撃軸（装備前提・上級）**: 漆黒のドレス＋漆黒の弓＋（龍牙 or 深蝕ライフル）で衝撃供給を
   ループ化し、エレクトラ/クリスティ/アヤメ/エティアの消費トリガーを回す。【虚空】【猛毒】。
3. **ハイブリッド**: 崩壊2連打で防御0→衝撃フロントの【烈風】（衝撃5以上参加者の合計攻撃力加算）
   で大ダメージ。
4. **対厄災**: 有効属性・ギミック対策（耐性100%化、全体ヒーラー、攻撃デバフ、開幕マナ）を優先し
   汎用軸から組み替える（contents-and-rewards.md §迎撃戦）。
