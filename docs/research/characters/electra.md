# エレクトラ（【高性能アンドロイド】）装備考察

2026-08-19。ソース: [wikiru個別ページ](https://dotabyss.wikiru.jp/?%E3%80%90%E9%AB%98%E6%80%A7%E8%83%BD%E3%82%A2%E3%83%B3%E3%83%89%E3%83%AD%E3%82%A4%E3%83%89%E3%80%91%E3%82%A8%E3%83%AC%E3%82%AF%E3%83%88%E3%83%A9)・武器/防具/アクセページ・醜女氏note。

## キット（Lv10/Lv5基準）

- SSR / ルクスノヴァ / 無属性 / バック / 衝撃 / 銃 / マント。**初期実装唯一の飛行キャラ**（地上系の近接攻撃・範囲が当たらない。遠距離・大型ボス攻撃は届く）
- アビ1: 会心率+15〜25%（覚醒1/3凸: チャージ効率+5/9.5%）
- アビ2: **会心時、攻撃UP【最大8%】付与【累積/最大40%】**（覚醒1/4凸: 会心ダメ+12.5/23.7%）
- アビ3 リチャージャー: 敵撃破時スキル5〜10%チャージ（**覚醒2/4凸: 開幕衝撃4/8**）
- スキル レーザーガトリング（チャージ40）: 前方範囲【15HIT/合計90〜138.4%】＋**自身に衝撃3付与**。
  FC追加効果: **衝撃5消費**で倍率264%（マナ覚醒1で271%〜）
- 評価: 会心→攻撃累積→撃破→チャージ短縮の自己完結ループ。全体攻撃としてはヒマリの約3倍の倍率

## エンジン構造（装備選定の根拠）

1. **会心が全ての起点**: 会心のたびに攻撃+8%（40%まで）。15HITスキルなので会心率が高いほど
   数秒でカンストし、覚醒の会心ダメも乗る。素5%+アビ25%+絆振りでベースを作り、装備でさらに盛る価値が最大
2. **衝撃収支は自前でほぼ回る**（スキル毎+3、FC毎-5 → FC連打時のみ純減2/回）。
   2凸開幕8、または供給装備（漆黒のドレス/弓、FC時衝撃付与エンチャント）で黒字化
3. **「衝撃消費時」トリガーと最高相性**: FC参加のたびに確実に5消費するため、
   消費時トリガー効果（深蝕のライフル、衝撃系エンチャント）の稼働率が全キャラ中最高クラス
4. 飛行のため被弾が少ない → 防御デメリットの許容度が高い
5. **注意（バグ）**: 飛行が原因でフレデリカの「バック全体に衝撃付与」の対象から漏れる報告あり
   （2026-06-30コメント）。地上バック前提の紋章供給は当てにしない

## OP（エンチャント）の狙い

厳選余地は実質**武器の第3枠（完全ランダム）**と各枠の効果値:
- 深蝕のライフル: 枠1=固有(固定)、枠2=攻撃上昇(値のみ厳選)、**枠3=厳選対象**
- フォレストマント: 枠2=防御上昇固定(値のみ)。アクセも選択余地なし

武器第3枠の優先順:
1. **会心率上昇**（アビ2ループの加速・最優先）
2. **紋章:衝撃会心率UP**（消費時15秒、最大20%。FC運用なら実質常時）
3. **紋章:衝撃付与**（FC時衝撃1〜2 → FC毎の純減2を相殺し完全自給。供給役不在の編成ならこちらを1位に）
4. 会心ダメージ / 与ダメージ
5. 連撃率（行動頻度→会心試行増だが、連撃率の正確な仕様は未解明 `[?]`）
- 紋章:情熱系・状態異常系はハズレ（紋章不一致/ボスに通らない）

## 絆・育成の優先（コメント欄の定説と一致）

絆ポイントは**会心率→攻撃**の順。アビリティは 2（会心時攻撃）＞1（会心率）＞3 の順で10へ。
凸は2凸（開幕衝撃8の半分=4）で運用が大きく安定。
