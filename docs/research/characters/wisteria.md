# ウィステリア（【赤焔の弓使い】）装備考察

2026-08-19。ソース: [wikiru個別ページ](https://dotabyss.wikiru.jp/?%E3%80%90%E8%B5%A4%E7%84%94%E3%81%AE%E5%BC%93%E4%BD%BF%E3%81%84%E3%80%91%E3%82%A6%E3%82%A3%E3%82%B9%E3%83%86%E3%83%AA%E3%82%A2)・武器/防具/アクセページ・醜女氏note。

## キット（Lv10/Lv5基準）

- SSR / ミレスガルド / 火 / バック / 情熱 / 弓 / マント。HP2508・攻1848・防992（Lv30+5凸）
- アビ1 炎の弓使い: 【情熱5以上】通常攻撃に炎上【30秒/50%】付与（覚醒1/3凸: 攻防HP+5/9.5%）
- アビ2 スナイプショット: **最も遠い敵を狙う**＋攻撃範囲+100%＋【情熱5以上】状態異常付与確率+30%
  （覚醒1/4凸: 連撃率+16.6/19.1%）
- アビ3 バーニングパニッシュ: 炎上中の敵への与ダメ+15%（**覚醒2/4凸: 30秒毎に情熱1/2 自己供給**）
- スキル ヴァーミリオンアロー（チャージ40）: 単体【4HIT/528.4%】(完凸600%)＋情熱1自己付与。
  **FC追加効果: 無条件で倍率616.4%**（完凸700%）← 紋章条件なしは希少
- wiki評価: 「全キャラ中トップクラスの対単体火力」。ただし2つのAI問題:
  ①アビ2「最も遠い敵を狙う」でバックなのに前線へ突出する
  ②スキルは表記「最も近い敵」だが実際は後列狙い→複数ボス戦でダメージ分散

## エンジン構造

1. **主力はFC時の単体616%**。FC追加効果が無条件なので、崩壊軸バックに混ぜるだけで機能する
2. **情熱5がアビ1・2の起動条件**だが、自前供給はスキル+1/発と2凸の30秒毎+1のみで細い。
   情熱は非消費なので一度5に達すれば永続 → 「立ち上がりをどう速くするか」の問題
3. 炎上シナジー（アビ1→アビ3特攻15%）は**大ボスに状態異常が通らないため道中・深淵向け**。
   対ボス火力は素の倍率×会心で出す
4. 突撃AIで被弾する前提のケア（回復・防御アクセ）が必要

## 推奨装備

| 部位 | 第一候補 | 根拠 | 代替 |
|---|---|---|---|
| 武器 | **鳳翼の神弓**（情熱/ユニーク） | 会心率+20%が単体ボスキラーの期待値に直結（情熱20スタックの+20%と合算で高会心域）。撃破時2%の情熱ばら撒きはおまけ | 深蝕の弓（追撃30%＋枠2が情熱状態異常確率UP=炎上ビルド・雑魚向け）/ 機械式複合弓（会心率+情熱攻撃UP、非ユニーク最良） |

| アクセ | **氷河のタリスマン** | 唯一の防御基礎値アクセ（実測最大~300）で突撃AIの被弾を緩和。情熱毎凍結耐性はおまけ。※イベント限定・値厳選 | 対応耐性指輪（厄災戦）/ 煉獄・氷河のモニュメント（情熱付与時耐性、対厄災特化） |

## OP（武器第3枠）の優先度

1. **会心率上昇** — 単体アタッカーの期待値最優先（FAQの絆指南とも整合）
2. **紋章:情熱会心率UP** — 付与時15秒。スキル毎に自己付与+1があるので準常時稼働
3. 与ダメージ／会心ダメージ／攻撃上昇
4. スキルチャージ効率 — 主力スキルの回転。情熱スタックのチャージ+1%/個と合算
5. 紋章:情熱状態異常確率UP — 炎上ビルド（道中・深淵）専用
- ハズレ: 紋章:衝撃系すべて

## 育成・運用

- 絆: **会心率→攻撃**。凸は**2凸が分水嶺**（30秒毎情熱1の自己供給でアビ1・2の起動が自立）
- アビ強化の優先度は低め（炎上系はボスに通らないため）。3→1→2 の順で余裕があれば
- 情熱5の立ち上げ: 漆黒の剣（開幕火水土全体に情熱1）持ちを編成 / ミルティーユのFCばら撒き /
  マリナ / FC(崩壊)参加のたびにスキル発動で+1
- **突撃対策必須**: ヒーラー（ミルティーユ/ヒナギ）と攻撃デバフ（フレデリカ/シャノン）を同編成に
- 複数ボス戦（高難度）はスキルが分散するため単体ボス・迎撃戦向きの運用が最適
