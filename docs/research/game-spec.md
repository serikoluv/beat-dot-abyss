ゲーム概要: ドット絵×アビス探索RPG。2026-06-11 サービス開始（PCブラウザ/スマホ、DMM）。
最大10体編成のオートバトル。`[確]`

## 1. キャラクターの基本属性

### 1.1 レアリティ
- SSR / SR / R の3段階 `[確]`

### 1.2 スタンス（役割） `[確]`
| スタンス | 役割 |
|---|---|
| フロント | 近接壁役。HP・防御が高く前線維持。近づく敵を受け止める |
| バック | 遠距離攻撃・回復・状態異常・弱体。耐久は低い |
| アシスト | 戦闘に直接出ず、後方から支援。**自身のステータスがフロント/バックへの補正値になる** |

- 編成の定番は「フロント4・バック3・アシスト3」の10体 `[推]`（コンテンツにより変動しうる）

### 1.3 武器タイプ `[確]`
- スタンスをさらに細分化する分類。例: フロント内でも「片手剣」「大剣」、他に弓・ナックル（拳）・銃・魔導書など `[推]`（完全な一覧は未取得 `[?]`）
- 武器・防具は武器タイプ（キャラのタイプ）に合ったものしか装備不可 `[確]`
- 敵構成・ステージ特性により武器タイプのバランスも編成上重要 `[推]`
- ユニーク装備の充実度が武器タイプごとに異なる（醜女氏 note の主題の一つ）`[推]`

### 1.4 属性と紋章 `[確]`（関係の正確な整理は `[?]`）
- 属性は6種: **火・水・土・光・闇・無**
- 紋章は2系統: **情熱**（火/水/土）と **衝撃**（光/闇/無）
- 敵には弱点属性があり、弱点属性攻撃でダメージ増（表示: 白=等倍、赤=有利、青=不利）
- 紋章統一（情熱パ/衝撃パ）でスキル・アビリティ・FCのシナジーが大きく向上
- 傾向: 情熱=持続力・状態異常寄り、衝撃=バースト火力寄り `[推]`
- `[?]` 「紋章効果が一定以上」という FC 条件があるため、紋章は戦闘中に蓄積する**数値リソース**でもある模様。キャラごとの「衝撃を溜める」等の記述もこれに関連か。**蓄積の仕組み（何で溜まる/消費するか）は最優先の要確認事項**

## 2. スキル・アビリティ

- キャラは少なくとも以下を持つ `[推]`:
  - **通常攻撃**
  - **スキル**（例: 前方の敵全体を攻撃。スキルチャージ効率というステータスが存在 → チャージ制 `[推]`）
  - **アビリティ**（パッシブ。例: 「回避率上昇＋回避成功時に衝撃を付与」「通常攻撃2回ごとに次の通常攻撃強化」）
  - **フォースチェイン追加効果**（FC参加時に発動する強化効果。発動に紋章数などの条件付きの場合あり）
- 限界突破でスキルレベルが上昇 `[確]`
- SSR は限界突破でアビリティの覚醒効果が解放/強化 `[確]`
- 状態異常が多数存在（炎上・凍結・喪失など）。付与側・耐性側の両方がある `[確]`
- トークン（召喚物）を出すスキルも存在（例: ニナのFCは自身の120%のトークンを60秒召喚）`[推]`

---

## 3. マナクリスタルとフォースチェイン（FC）

- **マナクリスタル**: 戦闘中に溜まるマナ（画面右下ゲージ）を消費して発動する切り札スキル。コマンダー（プレイヤー側）専用 `[確]`
- マナクリスタルごとに効果が異なり、入手・強化・セットの概念がある `[確]`
- 発動時に**条件を満たすと追加効果**が発動（例: 紋章効果が一定以上）。条件を満たしやすい編成が重要 `[確]`
- **フォースチェイン**: マナクリスタル発動時に発生する連携。**発動したマナクリスタルに該当するスタンスのキャラが参加** `[確]`
- FC参加キャラはスキルの「FC追加効果」が発動し、通常より強力になる `[確]`
- バランス調整あり（2026-08-10: マナコスト減・効果時間増など）→ **データは調整履歴に追従する必要あり** `[確]`

## 5. 装備

- 部位は **武器・防具・アクセサリー** の3種 `[確]`
- 武器・防具は武器タイプ制限あり。アクセは自由 `[推]`
- パラメータ＋**エンチャント効果**で強化 `[確]`。分解も可能 `[確]`
- **ユニーク装備**: 主に深淵のクリア報酬。ランク1〜5があり、ランク5は深層のみ。FC発動時トリガーの効果を持つものも（例: フォレストマント=FC時攻撃力+50%）`[確]`
- 味方全体強化系の装備も存在（覇光の剣、深蝕のライフル等）`[推]`
- 装備の厳選（ドロップ/エンチャント）要素あり `[推]`

## 7. スキーマ設計に効く要点（まとめ）

1. **アシストは「ステータス→補正値」変換**なので、キャラのステ管理はスタンス毎に意味が変わる
2. **FC・紋章・マナクリスタルが編成評価の中核**。キャラ単体ではなく「マナクリスタルのスタンス指定 × 参加キャラのFC追加効果 × 紋章条件」の三つ巴で評価する必要がある
3. **育成状態（凸・絆・覚醒・シンクロLv）で性能が段階変化**する。マスターデータと所持状態の分離必須
4. **バランス調整が入る**ため、データにはバージョン/取得日を記録する
5. ユニーク装備がキャラ評価を大きく変える（武器タイプ経由の紐付け）
