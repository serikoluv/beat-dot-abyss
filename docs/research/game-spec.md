## 1. キャラクターの分類軸 `[確]`

| 軸 | 値 | 備考 |
|---|---|---|
| レアリティ | SSR / SR / R | |
| 所属（勢力） | エルドラーナ / ミレスガルド / 千国連合 / ペルディオン / ルクスノヴァ | ルクスノヴァは排出率が別格に低く「実質UR」。勢力クエスト・深淵ミッションの縛り対象 |
| 属性 | 火 / 水 / 土 / 光 / 闇 / 無 | 敵に弱点属性あり（有利=赤字/不利=青字ダメージ表示） |
| 紋章 | 情熱 / 衝撃 | **属性から導出される**（火水土→情熱、光闇無→衝撃）。独立して選べない |
| スタンス | フロント / バック / アシスト | wiki表記は「スタイル」 |
| 武器種 | 片手剣・大剣・拳（フロント）/ 弓・杖・銃・魔導書（バック）/ ピッケル（アシスト） | 全8種。スタンスと厳密に対応 |
| 防具種 | 鎧（フロント）/ マント（バック）/ 作業着・服（アシスト） | |

- 同名キャラの別衣装（例:【渚のメイド】ニナ＝水着版）は**完全に別キャラ（別レコード）**。
  属性・スタンス・武器種まで変わる（恒常ニナ=フロント/光/拳、水着ニナ=バック/無/弓）。
- キャラ数: 2026-08-12 時点で65体（SSR33 / SR16 / R16）＋8/15実装ヘイリー。
  → 全キャラの生データは `data/master/characters.csv`

### 編成枠 `[確]`
- **アシスト最大3枠＋フロント/バック合計最大7枠**（内訳自由）の最大10体。
- 最低出撃要件は各スタンス1体（計3体）。全スタンス1体以上いないと編成登録不可。
- デフォルトはフロント3/バック4/アシスト3。現環境はバック偏重（フロント1〜2）が主流。
- **配置番号がFCのスキル発動順を決める**ため、並び順自体が最適化変数（§4）。

### スタンスの意味 `[確]`
- フロント: 近接壁役。タンク型（低攻高耐久）とアタッカー型（高攻低耐久・回避型）に二分。
  回避型は回避時に後退し戦線維持に不向き。
- バック: 遠距離攻撃・回復・支援。能動的な回復手段はFCしかないため自動回復ヒーラーほぼ必須。
- アシスト: 直接戦闘に出ず、**パラメータと状態異常耐性の一部がフロント・バック全員に加算**
  される。武器は全員ピッケル。攻撃を受けないので低レアでも運用可。

## 2. ステータス `[確]`

個別キャラページの詳細パラメータ表に定義される15項目（各「初期/最大」のペア、かつ
「ベース値」と「アビリティ由来補正」の2表建て）:

> HP / 攻撃力 / 防御力 / 会心率(%) / 会心ダメージ(%) / 連撃率 / 回避率 / 弱点属性特攻 /
> チャージ効率 / 炎上耐性 / 凍結耐性 / 石化耐性 / 麻痺耐性 / 魅了耐性 / 喪失耐性

- キャラ一覧の HP/攻撃/防御 は「**Lv30+5凸**」基準のベース値（一次ソースの実数はここ）。
  個別ページの詳細表は未記入が多い。
- 会心率は素で全キャラ5%（ルクスノヴァのみ10%?）`[推]`
- **連撃率**: 公式説明なし。「攻撃が2連撃になる率」との推測が有力 `[推]`。100%超の挙動は不明
- **チャージ効率**: スキルゲージの溜まり速度。「CT ÷ (1+効率)」の除算と推測 `[推]`。被弾でも増加 `[推]`
- 魔導書キャラの「攻撃力」は回復性能を表す `[確]`

## 3. 紋章システム（最重要メカニクス）`[確]`

- 紋章はキャラが1種だけ持つ「マナの波長」で、**戦闘中に蓄積するスタック（最大20）**。
- **情熱**（火水土）: 1スタックごとに会心率+1%・チャージ効率+1%。主にスキル発動等で獲得。
  「情熱5以上で追加効果強化」型が多く、**消費しない**（溜めきれば永続）。安定型。
- **衝撃**（光闇無）: 1スタックごとに攻撃力+1%・チャージ効率+1%。開幕・条件付与で獲得。
  「衝撃を5消費して強化」型が多く、**消費する**。瞬間火力型・枯渇リスクあり。
- **獲得手段**: 自身のスキル/アビリティ、他キャラからの付与、装備エンチャント、アビスコード。
- **地雷仕様**: キャラは本来と異なる紋章を付与されると**消せず、本来の紋章も増えなくなり
  紋章機能が停止する**。開幕ランダム付与系の装備・アビスコードは事故源。
  2026-07-10 修正でユニーク装備の付与は対応属性限定になったが、一部残存。
  情熱は事前付与で上書き事故を予防できる。衝撃は消費で0になるため常時リスクあり。
- 衝撃の消費境界: 「ちょうど0になる消費」では消費トリガー装備（龍牙のナックル等）が
  発動しない実測報告あり `[推]`

## 4. マナ・マナクリスタル・フォースチェイン（FC）`[確]`

編成評価の中核。**現環境は「バックFC連打ゲー」**。

- **マナ**: 戦闘中に溜まるリソース（上限10 `[推]`・アサルトモード中断成功で10まで回復）。
  溜まり方の正確な仕様は未確認 `[?]`。マナチャージ持ちキャラ（メリッサ/ジェンマ/エミリー等）
  や「マナチャージ効率」エンチャントで加速。
- **マナクリスタル**: フロント/バック/アシスト対応の3枠に1つずつセットする切り札。
  メインクエスト等で入手、施設「研究所」で強化（Rank制）。装着解除は編成画面の
  「一括解除」のみ。
- **FC発動の流れ**: マナ消費 → クリスタル固有の「チェイン効果」＋**参加キャラのスキル一斉発動**
  （FC追加効果込み）。FC中は時間停止するが参加者のスキルゲージは増加する。
- **参加ルール**: クリスタルに対応するスタンスのキャラのうち「スキル発動可能状態」の者が
  **配置番号順**に、クリスタルの最大チェイン人数（2〜5）まで選出される。
  スキル発動中・一部状態異常（喪失・麻痺等）・戦闘不能は参加不可。
  → 撃たせたいキャラを若い番号に、消費したくないキャラ（衝撃温存）や長モーションキャラは後方に。
- **FC追加効果の条件**: 主に「紋章:情熱（または衝撃）5以上の味方の参加」。
  条件充足者はオーラ表示で判別可。
- **オート発動条件はクリスタルごとに固定**（例: フロント系「敵3体以上」、【崩壊】「マナ8以上」）。
  フロント枠を空にしないと【崩壊】がオートでほぼ出ない、等の干渉がある。
  「チェイン対象が全員参加可能であること」も事実上のオート条件 `[推]`。
- **全11種の効果・条件・オート条件の一覧**: → `data/master/mana_crystals.md`（作成予定）。
  代表: 情熱【崩壊】=バック4人・消費4・全体攻撃＋防御DOWN20%（情熱5以上の参加者×7.5%加算、
  最大50%。2連打で実質防御0）。現環境の主軸。

## 5. スキル・アビリティ `[確]`

- **スキル**: 1キャラ1つ。チャージ制（例: ニナ=チャージ50）。時間経過で自動発動、FCでも発動。
  レベル段階は **Lv1〜5 ＋ マナ覚醒1〜5**（=5凸〜9凸に対応）の10段階。
  各段階は「本体効果」＋「**FC追加効果**」の2部構成。
- **アビリティ**: 1キャラ3つ。パッシブ。**Lv1〜10**（技能元素で強化、§6）。
  SSRは凸ごとに「**覚醒効果**」が追加（どの凸でどのアビリティが覚醒するかはキャラ依存、1〜4凸）。
- 効果テキストの数値は【】括り。「発動条件付き通常攻撃強化」「N秒毎」「行動N回毎」
  「回避成功時」などのトリガー型が多い。
- 効果の重複・累積は個別差があり**テキストから判別不能**（累積するもの/時間延長のみ/どちらも
  無いものが混在）。累積上限が明記される場合のみ確実（例:【累積/最大50%】）`[確]`
- 主語の表記ゆれ（「自身の」「味方の」「主語なし」）が多く、データ化時に解釈が必要 `[確]`

### 状態異常一覧 `[確]`（醜女氏まとめ。ゲーム内ヘルプなし）
| 異常 | 効果 |
|---|---|
| 炎上 | 時間経過ダメージ |
| 凍結 | 行動間隔延長＋連撃率・チャージ効率低下。一定回数行動で解除 |
| 石化 | 行動不能＋被ダメージ増加（被弾時確率解除） |
| 麻痺 | 行動不能 |
| 魅了 | 一部行動阻害 |
| 喪失 | スキルチャージ停止・スキル使用とFC参加が制限 |
| 氷獄 | 行動不能 |

- 大ボス（厄災）には状態異常が基本通らない `[推]`
- アサルトモード移行時、ボスへのデバフは解除される `[確]`

### 戦闘システムの要点 `[確]`
- 基本オート進行、3倍速対応。敗北=全滅、時間切れあり。戦闘前に敵の弱点・耐性を確認可能。
- **アサルトモード**: ボスHP一定以下で紫ゲージ追加。時間内に削れないとHP全回復＋強力攻撃
  （厄災級は即死級）。中断成功でマナ10回復。アサルト必殺技は**必中**（回避型が落ちやすい）。

## 6. 育成システム `[確]`

| 要素 | 仕様 | 素材 |
|---|---|---|
| レベルシンクロ | 10体をLv30にすると解放。以降**全キャラのレベルが統一**。リセット無料・素材返還 | EXP/ゴールド/記憶の欠片（Lv71〜120の必要量テーブル取得済み） |
| レベル上限解放 | Lv60→70→80→100 は**メモリーキューブ**（H4章/H6章/VH4章の厄災初回クリア報酬） | |
| 限界突破（凸） | 同名キャラで実施。1〜4凸: SSRのアビリティ覚醒効果解放。4凸で「マナ覚醒」、5〜9凸: スキルLvのみ強化（マナ覚醒1〜5）。9凸=完凸=同キャラ10体。以降の被りは覚醒Pt→アビスシール | 同名キャラ |
| アビリティ強化 | 各アビリティLv1〜10 | ゴールド＋技能元素（属性別×初/中/上級、スタンス別×同、特級）。Lv10まで累計: 金93,000/各元素60ずつ/特級2 |
| 絆Lv | プレゼントで上昇（Lv30まで累計「うれしいプレゼント」672個）。絆ポイントでステータス強化（フロント/バック=会心率、アシスト=チャージ効率が追加対象） | プレゼント |
| 覚醒強化 | 覚醒ポイントを状態異常耐性に振り分け。リセットにアビスジェム100 | 覚醒Pt |
| 好感度 | **好感度5で全アビリティ解放**（娼館/酒場コンテンツ経由） | |

- 「潜在能力」「才能」に相当するシステムは存在しない `[確]`
- 育成効果の伸びは「初期10%→最終100%」型が多く、**無育成時の性能が極端に低い**キャラが多い
  → 評価は育成段階を明示して行う必要がある `[確]`

## 7. 装備 `[確]`

- 部位: **武器（武器種8: キャラ固定）/ 防具（防具種3: キャラ固定）/ アクセサリ（自由）**
- レアリティ: コモン / エピック / レジェンダリー / ユニーク
- **エンチャント構造**:
  - 武器: コモン=1枠固定、エピック=2枠固定、レジェンダリー=2枠固定＋3枠目ランダム、
    ユニーク=1枠目固有効果＋2枠目値ランダム＋3枠目ランダム
  - 防具: コモン/エピック=なし、レジェンダリー=1枠、ユニーク=固有＋汎用1枠
  - アクセ: 基礎効果（防御 or 耐性、**値はレアリティ無関係にほぼランダム**）＋ユニークは固有効果
- **ユニーク装備**: 固有効果が本体。多くに「**1編成につき1本のみ**」制限。
  主な入手: メインH/VH特定ステージ・探索特定階層・**深淵**（ランク5は深層）・イベント限定・
  迎撃戦（アクセ）。**イベント限定装備は終了後の入手手段なし**（取り逃し厳禁）。
- 装備枠500。自動分解は**アクセを一括ロックしてから**（迎撃戦産で貴重）。
- 汎用エンチャントの主要パラメータ: HP/攻撃/防御/会心率/連撃率/状態異常付与確率/
  スキルチャージ効率/マナチャージ効率/探索力/与ダメージ/会心ダメージ
- 紋章系エンチャント（「情熱付与時〜」「衝撃消費時〜」）は紋章一致キャラでのみ機能。
- 全武器・防具16種・アクセ11種の一覧データ取得済み → `data/master/` に展開予定
- キー装備（環境定義級）: フォレストマント（FC毎攻撃+50%累積・バック全員分）、
  漆黒のドレス/弓/ナックル/ライフル（紋章供給エンジン）、覇光の剣、深蝕のツルハシ
  （マナチャージ+10%）。詳細は `meta-environment.md`
