# ドットアビス コンテンツ・報酬仕様

最終更新: 2026-08-18（一次ソース読了ベース）。将来の「報酬回収の計画・自動化」の基礎資料。

## 1. 常設コンテンツ

### メインストーリー
- NORMAL → HARD（N6章クリアで解放）→ VERY HARD。章末は厄災（ボス）戦。
- H/VH の特定ステージがユニーク装備のドロップ源。VH解放で自動探索の獲得品質もVH相当に上がる。
- レベル上限解放のメモリーキューブは H4章 / H6章 / VH4章 の厄災初回クリア報酬。

### 深淵（エンドコンテンツ、ローグライト）
- N6章クリアで解放。現在130Fまで（2026-07-31拡張）。マス選択式（戦闘/強敵/ボス/イベント/宝箱/回復/ショップ）。
- 持ち込み: レベル・装備・凸すべて（**深淵中は編成・装備変更不可**）。
- **ゲートキー**: スタミナ500消費ごとに1個自動獲得（≒1日1個）。10階ごとに1個消費。
  **3倍ドロップ消費は1日1回**（戦闘ドロップのみ3倍。ショップ・イベント直入手は対象外）。
- **浸食率**: 戦闘+5%等で蓄積、100%でゲームオーバー（獲得品ロスト。ロストシグナル所持で救済）。
- **アビスコード**: 挑戦中限定の永続バフ。4系統（インパクト=衝撃系 / ラッシュ=情熱系 /
  セーフ=低浸食有利 / リスク=高浸食有利。対系統は相殺）×無印/改/真。所持上限20（深部調査で拡張）。
  系統累積5/10/15で恩恵。開幕紋章付与系コードは紋章違い事故の地雷。
- **研究（調査）ポイント = 帰還時所持コード数 × 攻略階層数（上限50F）× ボーナス補正**
  → **50Fで撤退が最効率**。深部調査は「コード所持上限（黄）」最優先。
- 報酬: 10F毎の到達報酬（1回きり）/ 月間報酬（報酬Ptレベル制・月末リセット）/
  月間ミッション（100石×15=1500石。勢力縛り130F帰還等の高難度含む）/
  コード図鑑（月次で約1600ジェム）/ ユニーク装備（ランク5は深層、90F〜の深層ショップ、
  101F〜の浸食ナゾの袋=未鑑定ユニーク）。
- セオリー: ユニーク武器目的の100F踏破は基本1回だけ→以降は開始チェックポイントから50F周回。
  アビスコインは持ち越し不可、90F〜ショップでランク5装備を買って帰る。宝箱の代償
  （HP-80%/浸食+80%）は地雷。防具は深淵で落ちない（普段はメイン6-3等で周回）。

### 迎撃戦（日課・タワーディフェンス風）
- 1日3回（敗北・撤退は回数消費なし）。防衛設備（兵器工場で開発）を事前配置して厄災を迎撃。
- レベル制（現在Lv26まで）。**Lv13から凱旋コイン200、Lv22からランク5アクセ**がドロップ。
  凱旋コイン→技能元素交換。アクセサリの実質唯一の入手源。
- **厄災ごとに有効属性が固定**され、汎用最強編成とは別の対策編成が要る:
  | 厄災 | 有効属性 | 主要ギミック/対策 |
  |---|---|---|
  | 氷河 | 土 | 凍結ばら撒き→聖浄の調べ・凍結の指輪 |
  | 飢餓 | 光 | 飢餓DoT（回復でスタック減）→全体ヒーラー必須。雑魚吸収→範囲処理。時間切れ級即死技あり |
  | 天使 | 闇（光×） | 眷属数で信仰Lv変動→雑魚処理。麻痺対策。魅了が有効 |
  | 煉獄 | 水・光 | **炎上耐性100%化ほぼ必須**。マナ吸収→開幕マナ要員。攻撃デバフ。凍結足止め有効 |
- 「大厄災を放置して厄災レベルを維持」「巡回でボスの種類を引き直す」等の運用技あり。

### 勢力クエスト（日課）
- N3章クリアで解放。1日3回・**スキップ不可**。勢力別ステージ、依頼元勢力の出身キャラが大幅強化。
- 報酬: 勢力ピース（招集ピース=SSR60%/SR40%排出、大勲ピース）、所属キャラの欠片、技能元素、
  各勢力5段階目クリアで専用プレゼント5個。

### 探索隊（放置コンテンツ）
- 最大3部隊、**上限12時間**（VIPで最大20時間）→ 1日2回の受け取りが必要。
  リーダーに探索力UP装備。武器の入手源のひとつ（階層指定）。

### 探索クエスト（日課）
- 1日3回＋ジェム消費で+3回。**撤退・エラー再起動で回数消失、敗北では消費しない**。
  時間経過でクエストが入れ替わるため報酬の質で選ぶ。

## 2. イベント（2026年、全14回の開催実績）

### 形式の類型
| 形式 | 資源 | 仕組み | 備考 |
|---|---|---|---|
| ストーリーイベント | スタミナ | ステージ周回→交換所 | 特効はPUガチャキャラのみ。第2回以降は特効なしでも回収可能な設計 |
| ラッキーボックス | スタミナ（メイン周回） | 箱ガチャ。目玉排出後に箱更新可（更新後の引き直し不可） | ボーナスクエスト（確率発生・ランク5武器）併設 |
| クリスタルハント | 専用挑戦 | ウェーブ討伐TA。**攻撃できるのはアシストのみ**の特殊ルール | 撤退ノーコスト。イベント限定ユニーク（つるはし系）配布 |
| 特別依頼（探索型） | スタミナ0 | 順次クリア。**編成バフ条件**あり | 報酬は勢力ピース中心 |
| 鏡影の回廊 | スタミナ＋専用アイテム | 周回で収集→ボス（キャラのVR模擬戦）→交換所 | |
| 凶化厄災戦 | 討伐許可証? | 討伐イベント。**2編成で挑む** | 限定ユニークアクセ（氷河のタリスマン等） |
| 育成イベント | スタミナ | PUキャラのアビリティ素材配布 | |

### 報酬回収の計画に必要なデータ構造（実績から）
- イベント名 / 回次（復刻あり: ラッキーボックス・クリスタルハント・鏡影は既に複数回）
- 形式タイプ / 開催期間（**終了時刻が 4:59 / 11:59 など不揃い**）
- **報酬受取期間**（本編終了後に別窓。例: 水着イベ本編8/10まで・受取8/17まで）
- イベントミッションの受取（受け忘れ警告がwikiに常設される程度に忘れやすい）
- 期間限定サブ要素（ボーナスクエスト等の別期間窓）
- **限定装備の有無**（終了後の入手手段なし=最優先回収対象）
- 開催履歴の一覧データ → `data/master/events.csv`（作成予定）。スケジュール源は
  wikiのイベントカレンダー＋ロードマップ画像。

## 3. 日次・定期の報酬回収チェックリスト（自動化候補）

**デイリー**
- ログインボーナス / ショップ無料パック（デイリータブ）
- 迎撃戦×3 / 勢力クエスト×3（スキップ不可）/ 探索クエスト×3
- 探索隊の受け取り→再派遣（12時間上限なので朝晩2回）
- 深淵ゲートキー消化（3倍消費は1日1回。10n階の手前で止めて翌日クリアの計画運用）
- スタミナ管理: 司令官Lvアップはミッション報酬の経験値でのみ発生→受取タイミングで
  スタミナ溢れを制御（「一括受取」は全タブ回収してしまうため個別受取）

**ウィークリー**
- ショップ無料パック（ウィークリー）/ VIPウィークリー報酬（無課金も受取可）
- 深淵2回帰還または撤退（突入→即撤退でも達成）

**マンスリー**
- フレンドポイント交換（毎月1日5:00リセット。スタミナ回復薬(中)×20推奨、ガチャチケ×1）
- 深淵ミッション15件（1500石）/ 深淵月間報酬 / アビスコード図鑑（約1600ジェム）
- ショップ無料パック（マンスリー）

**不定期**
- 隔週のお得イベント（深淵ドロップUP時に周回、報酬倍化時に討伐許可証消費）
- イベント: ミッション受取・交換所・限定装備の期限管理
