# 娼館（酒場）仕様と攻略

最終更新: 2026-08-18。ソース: [wikiru 施設/娼館](https://dotabyss.wikiru.jp/?%E6%96%BD%E8%A8%AD/%E5%A8%BC%E9%A4%A8)
（本文＋コメント欄の検証情報）。一般版の名称は「酒場」。

## 1. 基本ルール `[確]`

- 「営業」は基本1日1回（イベント等の営業券で追加可）。複数ターンのカードゲームで、
  配置スタッフの**満足度**の合計スコアを競う。
- スタッフ配置には**好感度（絆Lv）1以上**が必要。
- **スタッフの初期満足度 = 200 + 絆Lv × 10**（絆20 → 400）。配置キャラの絆上げがそのまま火力。
- 施設レベル（改造依頼で拡張）:
  | 酒場Lv | フロア/部屋 | ターン数 |
  |---|---|---|
  | 1 | 1フロア・3部屋 | 2 |
  | 2 | 2フロア・6部屋 | 4 |
  | 3 | 3フロア・9部屋 | 5 |
- 3階拡張条件: 満足度4000達成＋好感度20のキャラ1人＋鉱石アイテム（VHドロップの金アイテム20個交換）

## 2. ターンの流れとマーク `[確]`

1ターン = **営業カード配布(3枚)→1枚選択 → キャラの提案（娼館スキル）を1つ選択**

- マークは3種: **料理（赤）/ 接客（黄）/ ドリンク（緑）**
- スタッフに付いたマークが2種で **GOOD**、3種で **GREAT**
- 営業カード（3階解放後）: 種類・マーク・対象位置は**配布時にランダム**
  | 種類 | 対象 | 満足度 | フロア換算効率 |
  |---|---|---|---|
  | 全体付与 | 9部屋全員 | +5% | 45%/フロア（最強） |
  | フロア付与 | 1フロア3人 | +10% | 30%/フロア（最弱） |
  | 1か所付与 | 1部屋 | +80% | 数値単体では最大 |
- **提案（娼館スキル）は1営業につき1キャラ1回まで**。ターン数=使用回数（Lv3で5回）

## 3. スコア計算式 `[推]`（コメント欄の検証。概ね実測一致）

```
最終満足度(スタッフ) = 初期値 × (1 + カード%合計 + 提案%合計 + 評価ボーナス)
評価ボーナス: GOOD = +20%, GREAT = +100%
処理順: カード → 提案
```

- **すべて初期値に対する加算**（乗算ではない）。
- 「Great以上のスタッフ+50%」系は**使用時点でGreatのスタッフにのみ**適用（後からGreatになっても遡及しない）。
- `[?]` 2026-08-13 に「提案の倍率が記載より低く出る」という報告あり（カードは記載通り）。
  マイナス補正か計算仕様の未解明部分の可能性 → シミュレータでは補正係数を設定可能にする。

## 4. 報酬 `[確]`（実測）

| 合計満足度 | ソウル | ゴールド |
|---|---|---|
| 〜2000 | 100〜150 | |
| 3000 / 4000 | 200 / 250 | |
| 6100 | 300 | |
| 8938 | 540 | 28000 |
| 12455〜13713 | 810 | 35000 |
| **14070以上** | **864（上限）** | 39200〜42000 |

- 864ソウルは「娼館の経営戦略」（施設アップグレード）最大強化時の上限。
- 副賞: うれしいプレゼント5＋流行りのプレゼント3（**流行り = 最高満足度スタッフの所属**
  → 所属染めで狙った勢力のプレゼントを安定回収可能）。
- ソウルは交換所でアビリティ強化素材に交換。
- **実用目標: 毎回 14,070 以上（ソウル上限）**。それ以上はゴールドが微増するだけ。
  25,000 は一回きりのミッション「夜の帝王」用。

## 5. 提案（娼館スキル）の類型 `[確]`

全キャラ分の個別データ → `data/master/brothel_proposals.csv`

| 類型 | 例 | 所持者の傾向 |
|---|---|---|
| 勢力付与 | 「ランダムな『勢力』のスタッフ最大N体に『マーク』付与＋満足度+X%」 | SSR: 3体+20% / 2体+40% / クレハ1体+100%。SR: 2体+10%。R: 1体+0% |
| 連鎖付与 | 「『料理』が付与されているスタッフに『ドリンク』を付与」 | **ルクスノヴァ限定級**（エレクトラ料理→ド、ピコ ド→接客、ラヴェリア接客→ド、限定エミリー接客→ド）。人数無制限=GREAT量産の要 |
| 全体バフ | 「全てのスタッフの満足度+20%」 | ヒナギ/ホノカ/フィオナ(+20)、ヒマリ(+10) |
| 評価条件バフ | 「Great以上+50%」「Good以上+20〜30%」 | ウィステリア/マニョリア/ヴィーラ/リエラ(+50)、グラディア(+30)他 |
| 評価スケール | 「全スタッフに評価に応じたボーナス(Good20/Great50)」 | シルヴィアのみ |
| カード操作 | 「次ターンの営業カードが必ず『マーク』関連になる」＋全体バフ | SSR+10%（ミルティーユのみ+20%）、SR+5%、R+0%（Rは最終ターン無効） |

### 重要な確定テクニック
- **勢力付与の確定化**: 対象勢力のスタッフ数 ≤ 最大N体 なら付与先が確定する
  （例: 千国スタッフをヘイリー・ダリアの2人だけにすると、SR 2体付与が確実に両者へ）。
- **連鎖コンボ**: 全体カード（マークA）→「A持ちにB付与」→「B持ちにC付与」で多人数GREAT確定。
  例: ディアーナ(千国3体に料理)→エレクトラ(料理→ド)→ピコ(ド→接客)→シルヴィア(評価バフ)。
- カード引きが悪い場合、**提案選択前のタスクキルでやり直し可能**（2026-06-14時点。
  対策された報告と未対策の報告が混在 `[?]`。最終提案選択後は結果確定済みで落ちても報酬は貰える）。

## 6. 高スコアの定石

- 事前準備が支配的: **配置9人の絆Lvを上げる**（初期値↑）＋経営戦略最大化＋3階拡張。
- 14,070（ソウル上限）は「絆そこそこ＋GREAT複数＋Great+50%を2〜3回」で安定圏
  （実測: 好感度20前後の構成で確定気味に14,000超の報告複数）。
- 25,000（夜の帝王）は 絆Lv平均20前後＋理想手札（全体5%を序盤3連続など）の**リセマラ前提**。
  ルクスノヴァ連鎖持ちがいると要求が大きく緩む。
- フロアごとに勢力を統一すると勢力付与が事故らない。
